## 02. CSS Styling

Скріншоти:

- [02-css-browser](./screenshots/2-css-browser.png)
- [03-css-code](./screenshots/03-css-code.png)

Що було зроблено:

- Було пройдено другий розділ офіційного туторіалу Next.js — **CSS Styling**.
- Ознайомилась зі способами додавання стилів у Next.js.
- Перевірила, як глобальні стилі впливають на весь застосунок.
- Переглянула використання CSS Modules для стилізації окремих компонентів.
- Запустила локальний сервер і перевірила зміни у браузері.

Спостереження:

- У Next.js можна використовувати різні підходи до стилізації: глобальні CSS-файли, CSS Modules та utility-класи.
- Глобальні стилі зручно використовувати для базового оформлення всього застосунку.
- CSS Modules допомагають уникнути конфліктів назв класів, оскільки стилі застосовуються локально до конкретного компонента.
- Зміни у стилях швидко відображаються у браузері під час роботи локального сервера.

Питання та роздуми:

- У яких випадках краще використовувати CSS Modules, а коли Tailwind CSS?
- Чи зручно підтримувати великий проєкт, якщо використовувати кілька підходів до стилізації одночасно?
- Мені здається корисним, що Next.js дозволяє обирати спосіб стилізації залежно від потреб проєкту.
